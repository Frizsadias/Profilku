# Frizsa Dias Puspitasari — Portfolio Website

Portfolio website untuk Full Stack Developer dengan spesialisasi SIMRS.

## 🚀 Deploy ke Vercel

### Cara 1: Via Vercel CLI
```bash
# Install Vercel CLI
npm install -g vercel

# Deploy
vercel

# Atau untuk production
vercel --prod
```

### Cara 2: Via Vercel Dashboard (Recommended)
1. Push project ini ke GitHub
2. Buka [vercel.com](https://vercel.com) → Login
3. Klik **"Add New Project"**
4. Import repository dari GitHub
5. Biarkan semua settings default → Klik **Deploy**
6. Done! Website sudah live ✅

### Cara 3: Drag & Drop (Paling mudah!)
1. Buka [vercel.com/new](https://vercel.com/new)
2. Drag & drop folder `frizsa-portfolio` ke browser
3. Website langsung live dalam hitungan detik!

## ✏️ Kustomisasi

Edit file `index.html` untuk menyesuaikan:
- **Email**: Ganti `frizsa@email.com` dengan email asli
- **LinkedIn**: Ganti URL LinkedIn
- **GitHub**: Ganti URL GitHub  
- **CV/Resume**: Tambahkan file `resume.pdf` di folder yang sama
- **Konten**: Update pengalaman kerja, project, dll.

## 📁 Struktur File

```
frizsa-portfolio/
├── index.html      ← Website utama (semua dalam satu file)
├── vercel.json     ← Konfigurasi Vercel
├── resume.pdf      ← (opsional) File CV untuk didownload
└── README.md       ← Panduan ini
```
